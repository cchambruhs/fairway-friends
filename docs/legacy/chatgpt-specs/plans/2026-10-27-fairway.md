# Fairway Friends Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
**Goal:** Ship a private disc golf dashboard populated from three real UDisc cards.
**Architecture:** Vinext app with a protected D1-backed group store; a pure parser validates shared-card content. Client charts and comparisons derive from saved rounds.
**Tech Stack:** React, Vinext, D1, Chart.js, PapaParse, linkedom.
**Spec:** docs/superpowers/specs/2026-10-27-fairway-design.md
## Global Constraints
- Only user-submitted https://udisc.com/scorecards/scorecard_* links; no credentials or automatic discovery claims.
- Keep unknown PDGA identities unlinked; candidate matches require explicit confirmation.
- Incomplete rounds never count toward completed wins, comparisons, or averages.
- Retain licenses for reused packages; save all records server-side.
## Review Focus
- Duplicate imports update rather than multiply records.
- Equal scores earn shared wins and head-to-head ties.
- Missing holes remain null and never become zero scores.
- Arbitrary URLs and redirects cannot access internal endpoints.
- Source changes produce a visible import error with no database writes.
