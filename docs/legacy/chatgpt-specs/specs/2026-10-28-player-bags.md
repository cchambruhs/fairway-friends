# Player bags and manufacturer preferences
User asks players to set a top five disc list with plastic and weight, plus a sponsor or favorite manufacturer. Preserve the public scoreboard and all recorded scores. Extend only editable profile gear.
Use the existing ChatGPT sign-in. A signed-in visitor may self-claim one unclaimed player profile, then edit that bag. Claims are self-asserted, not UDisc-verified. The host may edit bags or release mistaken claims. Anonymous visitors can see bags but cannot claim or edit. Claim IDs and account identity stay server-side; imported round scores and owner-only PDGA edits remain protected.
Each bag contains zero to five ordered discs. Each populated disc needs a mold name; manufacturer and plastic are free text and weight is optional grams (1–250, max one decimal). Unknown values stay blank. Featured manufacturer can be a favorite or a clearly self-reported sponsor; never imply verified sponsorship. Use D1 unique constraints for profile/account ownership and transactional claim updates. Validate everything server-side.
