# Public clubhouse and player dashboards
User explicitly requests public access, anonymous UDisc card-link submissions, no duplicate cards, and rich per-player stat dashboards including distance where available.
Approach: keep the existing app and database. Allow anonymous read and validated shared-card submission. Protect CSV, refresh and PDGA editing with authenticated owner email from runtime secret. Do not expose public access until that protection is deployed. Store new cards atomically with primary-key conflict ignored; preserve saved cards on duplicate public submissions. Normalize URL query strings and trailing slash. Rate-limit new anonymous imports in D1. Preserve existing data and parse scores from upstream only, never trust submitted score JSON.
Profiles: a wide responsive stats dashboard accessible from any player name and shareable by ?player=username. Scoring uses completed rounds; documented activity (strokes, holes, course distance) includes scored holes in partial rounds, labeled. Include score-to-par history, scoring breakdown, aces, streaks, clean/under-par rounds, bounce-back rate, exact-layout course records, round history and head-to-head rivals. Measured throw distance is explicitly unavailable in shared cards. Course distance is metadata from hole lengths and must never be labeled actual thrown or walked distance. Existing metadata is enriched only from the seven existing exact scorecards. Owner PDGA form remains available.
