# Fairway Friends — approved design
Phone-friendly private dashboard for Caleb's disc golf group; UDisc remains the scorekeeper. Shared completed-round links import on demand; automated discovery is deferred until a supported source is available. CSV backup import, persistent records, round leaderboard, hole scores, player trends, wins/ties, head-to-head and per-layout comparisons. Use the three user-supplied cards as real initial data. Incomplete rounds are visible but excluded from completed-round standings and head-to-head records. PDGA numbers link to official profiles; verified identities only, explicit saved candidate confirmation for uncertain matches. Official ratings show source date and no invented live sync.
Approaches: direct UDisc automatic discovery is unavailable; shared links are selected by the user; CSV-only is a fallback. Use server-rendered scorecard content with strict URL allowlisting and clear fetch failures; CSV fallback if UDisc changes. Stack selected by builder: Sites Vinext, D1, React, Chart.js, PapaParse, linkedom. Private site access enforced by Sites; persistent group dataset behind that boundary. No user/password collection, no polling or bypassing upstream access controls.
